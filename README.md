# 💍 Wedding Jaitri — Photography Booking & Portfolio Website

Welcome to **Wedding Jaitri**, a creative and responsive photography website built to showcase timeless memories — from weddings and rice ceremonies to candid shoots and more.  
This project reflects the artistry of capturing emotions through elegant visuals and seamless design.

## 📸 Overview

**Wedding Jaitri** is a modern front-end web project designed for photographers to:

- Display their photo gallery and services
- Allow clients to explore wedding albums
- Enable contact or booking through dedicated pages
- Provide an elegant and responsive experience across all devices

---

## 🧩 Features

✨ **Fully Responsive Design**  
Adapts beautifully to mobile, tablet, and desktop screens.

🖼️ **Photo Gallery Integration**  
Large collection of high-quality wedding and event photos.

💡 **Dynamic Pages**  
Each page (About, Services, Moments, Kids Zone, Reviews) provides a smooth experience.

🎨 **Modern UI/UX**  
Clean typography, soft animations, and balanced color palette.

⚡ **Lightweight & Fast**  
Optimized assets ensure smooth loading and performance.
